# Versi HP dan tablet (31 Oktober 2026, K-217)

Lanjutan K-204 bagian 2. Pilihan pemilik (31 Okt):

- **Pemakai:** staf penjualan (tablet, input order), Owner (HP: dashboard, laporan, stok, notifikasi, persetujuan),
  kasir (tablet: penjualan langsung), admin/gudang (HP/tablet: cek stok, terima barang, catat hasil kirim, opname).
- **Akses:** WiFi toko dan dari luar toko lewat **Tailscale**. Laptop server harus menyala.
- **Bentuk:** web app terpasang (**PWA**): dibuka di Chrome/Safari lalu *Tambahkan ke layar utama*.

## Keputusan

- **K-217 Akses HP/tablet lewat Tailscale HTTPS.** Semua perangkat (di dalam toko maupun dari luar) membuka satu alamat
  `https://<nama-laptop>.<tailnet>.ts.net`. Laptop menjalankan `tailscale serve` yang meneruskan HTTPS ke BonsaiUrip
  di laptop itu. Alasan teknis:
  - sertifikat HTTPS sah dari Tailscale: cookie login yang aman (*Secure*) berfungsi dan PWA bisa dipasang;
  - lalu lintas terenkripsi ujung ke ujung, juga di WiFi toko, sehingga password tidak lewat jaringan terbuka;
  - tidak perlu membuka port internet, aturan firewall Windows, atau IP tetap; perangkat di WiFi yang sama tersambung
    langsung (tidak lewat internet).
  Akses `http://<IP-laptop>` tanpa Tailscale tidak didukung (cookie aman ditolak di http).
  Setiap perangkat masuk dengan akun penggunanya sendiri; izin per peran tetap berlaku.
- **Tampilan:** CLAUDE.md semula *desktop-first, tidak ada mobile-first*. Karena pemilik memakai HP, aplikasi dibuat
  **responsif**: menu samping menjadi laci di layar sempit, topbar ringkas, tabel bisa digeser, tombol ramah sentuh.
  Layar yang diprioritaskan di HP: Dashboard, notifikasi, persetujuan, cari/cek stok, order cepat, catat hasil kirim,
  penerimaan barang. Layar kasir tetap untuk laptop/tablet (lebar ≥ 1024 px).
- Tahap: A) akses Tailscale, PWA, halaman *Pengaturan › Akses HP/tablet* dengan panduan dan kode QR, kerangka
  responsif; B) layar prioritas di HP; C) printer struk dari tablet (Bluetooth/jaringan) bila dibutuhkan.

*Tahap A dan B selesai 31 Okt (versi 1.18.0). Tahap C (printer tablet) menunggu kebutuhan.*
