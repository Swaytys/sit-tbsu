# Masukan untuk versi 1.19 (31 Oktober 2026, K-218–K-220)

Masukan pemilik setelah mencoba Setup 1.18.0, dikerjakan setelah presentasi ke Owner UD. Sumber Urip.

- **K-218 Bahasa layar tanpa istilah teknis.** Penjelasan seperti "data lama (dari *Mulai dari nol*)", "Pustaka",
  "pengaman otomatis" membingungkan. Semua teks di halaman pengelolaan data dan installer ditulis ulang dengan bahasa
  pemakai toko (mis. "Data toko yang tersimpan di komputer ini", "Cadangan otomatis sebelum ganti data"). *Rencana.*
- **K-219 Buat data toko baru dari dalam aplikasi.** Owner bisa membuat data toko baru yang kosong (setup awal dari
  awal) tanpa menghapus data yang sedang dipakai dan tanpa memasang ulang; data yang sedang dipakai tersimpan dan
  bisa dipakai kembali. Di halaman masuk juga tersedia pilihan *Ganti data toko / Buat data toko baru* (dengan
  pengaman yang sesuai). *Rencana.*
- **K-220 Nama dan susunan halaman.** Tab *Data* diganti nama yang jelas (mis. *Data Toko & Pindah Komputer*) dan
  *Pemeriksaan data* dipisah ke tabnya sendiri (tidak tergabung). *Rencana.*

## Perbaikan 1.18.0 (31 Okt, sore)

- **K-221 Aplikasi gagal menyala setelah ditutup lalu dibuka lagi.** Pemilik melihat "Database tidak mau menyala
  (could not bind 127.0.0.1:54329)" dan "Server tidak menjawab dalam 60 detik". Penyebab: port 54329/7878 sedang
  dipakai program lain (di sini salinan demo BonsaiUrip milik pengembang). Peluncur hanya memeriksa port aplikasi
  di 127.0.0.1 (di Windows, port yang dipakai program lain di 0.0.0.0 tetap tampak kosong), tidak memeriksa port
  database sama sekali, dan menganggap server apa pun yang menjawab di port itu sebagai miliknya. Perbaikan
  (peluncur): port dianggap kosong hanya bila tidak ada yang menjawab dan bisa dipasang di 127.0.0.1 maupun
  0.0.0.0; port database yang terpakai pindah ke port kosong berikutnya (tercatat di `peluncur.json`); server yang
  menjawab hanya dipakai bila PID server yang dicatat peluncur masih hidup; server macet dimatikan dulu; sambungan
  database dicoba ulang selama database masih "starting up" (setelah mati mendadak). Versi tetap 1.18.0 atas
  permintaan pemilik. *Selesai.*
